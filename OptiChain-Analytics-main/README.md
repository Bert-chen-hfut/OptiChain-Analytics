## 📌 Project Overview
This project addresses the critical issue of logistics delivery delays in e-commerce (using the Brazilian E-Commerce Olist dataset). Rather than relying on reactive compensations, our system leverages machine learning to predict delivery delay risk proactively at the checkout/order placement moment. Furthermore, we translate model predictions into actionable managerial levers: **Dynamic SLA Commitment**, **Seller Dispatch Escalation**, and **Proactive Customer Retention Care**.
